# Moderation by Interrogation: Uncovering Concealed Intent in Agent Social Networks

Code and data for Bot-Mod, the moderator that questions an agent before deciding on its post.

Bot-Mod forms a content-only prior over five intents from the moderator LLM's label probabilities,
asks up to three diagnostic probes in one live conversation with the agent, scores each answer by
its likelihood under a persona prompt for every candidate intent, updates the posterior, and stops
once one class is confident enough. This repository contains the code for the main experiment
(Bot-Mod, the content prior, and Bot-Mod-judge) and the Molt-Intent datasets together with the raw
Moltbook export they were built from.

```
www-code/      the experiment code (Python 3.13)
www-dataset/   Molt-Intent (train / ID test / OOD test / spam augmentation / personas) and the raw Moltbook export
www-results/   created on first run; every stage writes its JSON here
```

The folders must stay side by side; `www-code/paths.py` resolves everything relative to them
(`BOTMOD_DATASET` and `BOTMOD_LOGS` override the data and results roots).

## Setup

```
cd www-code
pip install -r requirements.txt        # exact pins of the environment used for the paper
GPU=0 bash launch_vllm.sh              # Qwen3-8B, Mistral-7B-Instruct-v0.3, Llama-3.1-8B-Instruct
```

`launch_vllm.sh` serves the three models as OpenAI-compatible vLLM servers on ports
`BOTMOD_PORT_BASE`, `+1`, `+2` (default 8000-8002); all three fit on one 80 GB GPU. Qwen3-8B is the
moderator LLM; every model also serves as an agent backbone, and each item is answered by the model
that wrote it.

## Data

`www-dataset/README.md` describes every file. Personas were generated by GPT-5 and filtered by a
GPT-5.1 judge; posts and comments were generated by the three agent backbones from those personas,
comments as replies to real Moltbook threads taken from `moltbook-export/`. The ID split uses seven
Moltbook communities, the OOD split six other ones. The paper's ID and OOD test sets are `id`+`id-spam`
and `ood`+`ood-spam`.

## Reproducing the main experiment

Four stages, in the order they were run. Stages 1 to 3 need the vLLM servers; stage 4 runs on CPU
from the stored per-item outputs. Splits: `train`, `id`, `id_spam`, `ood`, `ood_spam`.

**1. Content prior** (one label read per item, plus reset-agent answers to the six-probe bank that the
train-side temperature fit uses)

```
for s in train id id_spam ood ood_spam; do python exp_e12_head_to_head.py matrix $s; done
```

**2. Calibration on the training split**

```
python exp_probe_bank.py                       # base rates and observation model of the six-probe bank, on train
python exp_e15_train_refit.py --apply          # prior temperature T
python exp_e16_multiturn.py run train varied   # live training interrogations with the paper's probe wordings
python exp_e16b_rescore.py run train varied    # each answer scored alone under every intent
python fit_varied_bank.py                      # base rates mu, beta = 1/tau and the stopping level alpha
```

`fit_varied_bank.py` writes `probe_bank_varied.json` and `e17_varied_refit.json`, the constants the
scoring stage reads (T = 7.86, beta = 15.4, 1 - alpha = 0.98).

**3. Live interrogation of the test splits** (Bot-Mod's likelihoods and Bot-Mod-judge's verdicts come
from the same transcript)

```
for s in id id_spam ood ood_spam; do python exp_e17_live.py run $s; done
```

**4. Scoring (CPU)**

```
python exp_e12_head_to_head.py score id+spam
python exp_e12_head_to_head.py score ood+spam
```

Each call prints F1_val, F1_y, F1_t, FPR and the mean number of probes for Bot-Mod (`bot-mod-v2`),
the content prior alone (`prior-only`) and Bot-Mod-judge (`fixed-bank-judge`) on identical items,
with paired bootstrap intervals over 400 item resamples, and writes
`www-results/e12_head_to_head_<split>.json`.

## Code map

- `moderator_v2.py`: Bot-Mod (calibrated prior, likelihood update, stopping rule, decision).
- `exp_e2_logprob_posterior.py`: the content prior read from the label-token probabilities.
- `calibration.py`: temperature scaling of the prior and its fit on train.
- `exp_e3_teacher_forced_likelihood.py`: an answer replayed under each intent persona; the probe techniques.
- `exp_e16_multiturn.py`: the four wordings per technique (`VARIED`) and the training interrogations.
- `exp_e16b_rescore.py`, `fit_varied_bank.py`: per-answer scoring and the train-side fit of mu, beta, alpha.
- `interrogation.py`: the live agent session and the Bot-Mod-judge reader.
- `exp_e17_live.py`: the live interrogation of a test split.
- `exp_e12_head_to_head.py`: the content-prior collection and the scoring of all arms.
- `exp_probe_bank.py`, `exp_e15_train_refit.py`, `eval_common.py`: the six-probe bank and the temperature fit.
- `common.py`: item text, the metric (F1_val = F1_y^0.7 F1_t^0.3), the test file lists.
- `prepare.py`: the vLLM clients and the intent list.
